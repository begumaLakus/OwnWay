**OwnWay** is an AI-driven holistic decision support system designed to model **Person-Environment (P-E) Fit** in higher education choices and career planning. Unlike traditional ranking-based systems, OwnWay integrates academic performance with psychometric data and socio-economic preferences to minimize academic dissatisfaction and optimize student success.

---

## 🎯 Vision & Problem Statement
Traditional university preference robots focus solely on numerical rankings, ignoring the psychological and social compatibility between a student and their chosen environment. **OwnWay addresses this gap by:**

* **Reducing Attrition:** Lowering academic drop-out rates caused by mismatched choices.
* **Scientific Assessments:** Integrating validated Psychometric Tests into the decision-making process.
* **MCDM Modeling:** Utilizing *Multi-Criteria Decision Making* to balance academic scores, city living costs, and social requirements.

> [!IMPORTANT]
> This project is being developed at **Zonguldak Bülent Ecevit University** and has been submitted to the **TÜBİTAK 2209-A** (University Students Research Projects Support Program) for evaluation.

## 🌟 Key Features

| Feature | Description |
| :--- | :--- |
| **Psychometric Engine** | Scientific tests measuring personality traits and professional inclinations (RIASEC framework). |
| **AI Recommendation** | A hybrid system calculating "Compatibility Scores" for university/department pairs. |
| **Campus Intelligence** | Real-time visualization of cost of living, social amenities, and success trends. |
| **Explainable AI** | Provides transparent reasoning on *why* a specific choice fits the user's profile. |

---

## 🏗️ System Architecture
The system follows a modular architecture as defined in the **Preliminary Design Document (PDD)**:

* **User Profile Management:** Secure and scalable storage for standardized user data.
* **Psychometric Test Module:** A weighted scoring engine transforming responses into quantitative personality maps.
* **Interactive Map Module:** A real-time filtered visualization layer for geographical data.
* **AI Recommendation Module:** The core logic unit executing decision support algorithms and ranking.
